# Veloce Motors

Showroom automotivo em HTML, CSS e JavaScript.

## Executar

Abra o arquivo `index.html` em um navegador moderno.

## Recursos

- Interface premium e responsiva
- Showroom e animações interativas
- Estoque com filtros
- Fichas detalhadas dos veículos
- Galeria de fotos internas e externas por veículo
- Simulador de financiamento e avaliação

## Observações

Algumas imagens e bibliotecas são carregadas de fontes externas e dependem de conexão com a internet. Fotografias adicionais usadas nas galerias servem como referência visual do modelo/família e não necessariamente representam a unidade anunciada.
